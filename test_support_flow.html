✅ مراجعة شاملة لصفحة الدعم والشراء

📋 1. هيكل الصفحة

  • ✅ تبويب الشراء (purchase-tab) - موجود
  • ✅ تبويب التبرع (donation-tab) - موجود
  • ✅ 3 باقات (Basic $299, Professional $599, Enterprise $999) - موجودة
  • ✅ قسم طرق الدفع للشراء (purchase-payment-methods) - تم إضافته
  • ✅ 4 طرق دفع (Crypto, Card, PayPal, Bank) - موجودة

🔒 2. CSRF Tokens

  • ✅ نموذج البطاقة (cardPaymentForm) - تم إضافة CSRF token
  • ✅ طلبات Crypto (fetch) - يحتوي على X-CSRFToken في الـ headers
  • ℹ️ PayPal & Bank - لا يحتاجان CSRF (مجرد buttons)

⚙️ 3. وظائف JavaScript

  • ✅ switchTab(tab, event) - يبدل بين تبويب الشراء والتبرع
  • ✅ selectPackage(packageName, price, event) - يختار الباقة ويُظهر طرق الدفع
  • ✅ selectMethod(method, event) - يختار طريقة الدفع ويملأ المبلغ تلقائياً
  • ✅ generateCryptoPayment() - يستخدم selectedAmount
  • ✅ handlePayPalPayment() - يستخدم selectedAmount
  • ✅ cardPaymentForm submit - يستخدم selectedAmount

💰 4. تمرير المبلغ

  • ✅ المتغير selectedAmount يُعرّف بـ 0
  • ✅ selectPackage تضبط selectedAmount = price
  • ✅ selectMethod تملأ حقل cardAmount تلقائياً
  • ✅ selectMethod تملأ حقل customAmount (crypto) تلقائياً
  • ✅ جميع دوال الدفع تستخدم selectedAmount كقيمة افتراضية

🎯 5. التدفق الكامل المتوقع

  1. المستخدم يفتح الصفحة → يرى تبويب الشراء (افتراضي)
  2. يضغط على باقة (مثلاً Professional $599)
    • ➡️ تُضبط selectedAmount = 599
    • ➡️ تُظهر قسم طرق الدفع
    • ➡️ تتحرك الصفحة للأسفل (smooth scroll)
  3. يختار طريقة دفع (مثلاً Crypto)
    • ➡️ يُظهر نموذج Crypto
    • ➡️ يملأ حقل customAmount بـ 599
    • ➡️ المستخدم يختار العملة (BTC/ETH/USDT)
    • ➡️ يضغط "إنشاء عنوان الدفع"
    • ➡️ يُرسل طلب للسيرفر مع المبلغ $599
  4. إذا ضغط على "تبرع"
    • ➡️ يُخفي قسم طرق الدفع للشراء
    • ➡️ يُصفّر selectedAmount
    • ➡️ يُظهر تبويب التبرع
    • ➡️ المستخدم يُدخل المبلغ يدوياً

🔍 6. نقاط التحقق على المحلي

  1. ✅ افتح http://localhost:8080/auth/support
  2. ✅ تأكد من ظهور تبويب "شراء النظام" (نشط)
  3. ✅ اضغط على أي باقة → يجب أن تظهر طرق الدفع بسلاسة
  4. ✅ اضغط على طريقة دفع → يجب أن يكون المبلغ مملوء مسبقاً
  5. ✅ اضغط على "دعم المشروع" → يجب أن تختفي طرق الدفع للشراء
  6. ✅ افتح Console → يجب ألا يكون هناك أخطاء JavaScript

📝 ملخص التعديلات

  • ✅ إضافة قسم طرق الدفع داخل تبويب الشراء (purchase-payment-methods)
  • ✅ تعديل selectPackage لإظهار طرق الدفع عند اختيار الباقة
  • ✅ تعديل switchTab لإخفاء طرق الدفع وتصفير selectedAmount عند التبديل للتبرع
  • ✅ تعديل selectMethod لملء حقول المبلغ تلقائياً (cardAmount و customAmount)
  • ✅ إصلاح handlePayPalPayment لاستخدام selectedAmount
  • ✅ إصلاح cardPaymentForm لاستخدام selectedAmount
  • ✅ إضافة CSRF token لنموذج البطاقة
  • ✅ إضافة id="cardAmount" لحقل المبلغ في نموذج البطاقة
