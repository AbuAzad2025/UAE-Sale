# Documentation index

Documentation is intentionally split so production readers and developers do
not have to wade through each other's material.

## Production (`docs/production/`)

- `USER_GUIDE.md` — bilingual (AR/EN) human-facing user guide.
- `DEPLOYMENT.md` — deployment and operations.
- `FULL_USER_GUIDE.md` — machine-readable public guide consumed by the local AI assistant.
- `OWNER_USER_GUIDE.md` — machine-readable owner-only guide consumed by the local AI assistant.

## Development (`docs/development/`)

- `TECHNICAL_STATUS.md` — architecture, isolation, security and finance status.
- `MIGRATIONS.md` — migration chain and golden rules.
- `CHANGELOG.md` — version history.
- `LOCAL_AGENT_CONTEXT.md` — local agent context architecture.

The repository root is reserved for the project entry point (`README.md`) and
production configuration files. Development-only notes belong under
`docs/development/`.
