# Documentation index

Production documentation lives in `docs/production/`:

- `USER_GUIDE.md` — bilingual (AR/EN) human-facing user guide.
- `DEPLOYMENT.md` — deployment and operations.
- `FULL_USER_GUIDE.md` — machine-readable public guide consumed by the local AI assistant.
- `OWNER_USER_GUIDE.md` — machine-readable owner-only guide consumed by the local AI assistant.

The repository root is reserved for the project entry point (`README.md`) and
production configuration files.
